# Подключение статистики рекламы Facebook / Instagram

Платформа только читает статистику (право `ads_read`). Менять рекламу и тратить деньги с этим доступом нельзя.
Ключ вводит владелец на сервере сам. В чат ключ не отправлять.

Рекламный аккаунт: «Рек ак 5 - One English», ID `193386895288073`, портфолио «Рекламный компания 1».
Приложение OneEnglish находится в другом портфолио, поэтому аккаунт сначала открывают ему на просмотр.

## 1. Открыть рекламный аккаунт на просмотр
1. business.facebook.com → портфолио «Рекламный компания 1» → Настройки → Аккаунты → Рекламные аккаунты.
2. Выбрать «Рек ак 5 - One English» → «Назначить партнёра».
3. Ввести ID портфолио, в котором лежит приложение OneEnglish (виден в его настройках, «Информация о компании»).
4. Включить только «Просмотр результатов». Управление кампаниями не включать.

Сам аккаунт и Instagram остаются в своём портфолио, реклама продолжает работать как раньше.

## 2. Получить ключ
1. Портфолио с приложением OneEnglish → Настройки → Пользователи → Системные пользователи.
2. Выбрать системного пользователя (тот же, что для Instagram) → «Назначить объекты» → Рекламные аккаунты →
   «Рек ак 5 - One English» → «Просмотр результатов».
3. «Сгенерировать токен» → приложение OneEnglish → срок «Никогда» → отметить право `ads_read` → создать и скопировать.

Если права `ads_read` в списке нет: developers.facebook.com → приложение OneEnglish → «Сценарии использования» →
добавить сценарий с Marketing API (реклама), затем повторить шаг 3.

## 3. Ввести ключ на сервере
В PowerShell на своём компьютере:

    ssh -t root@89.126.198.159 "curl -fsSLo /root/ads-setup.sh https://raw.githubusercontent.com/inbr4in-cmyk/one/main/deploy/ads-setup.sh && bash /root/ads-setup.sh english.inbrain.kz"

Скрипт спросит ID аккаунта (`193386895288073`) и ключ (при вводе не виден), проверит доступ, покажет название
аккаунта и расход за 7 дней, сохранит значения в `/etc/one-english/env` (`OE_ADS_ACCOUNT_ID`, `OE_ADS_ACCESS_TOKEN`).

## 4. Проверить
Платформа → Финансы → «Реклама» → «Обновить». Дальше данные обновляются сами каждую ночь.
