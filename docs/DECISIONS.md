# Решения заказчика (имеют приоритет над ТЗ v3)

1. Стек: FastAPI + PostgreSQL, Vue 3 (веб), Flutter (iOS + Android) — после готовности веба.
2. Родители участвуют в чатах (родитель ↔ учитель / менеджер). Кто с кем может переписываться — настраивается правами в конструкторе ролей. (ТЗ v3 п.8 «Родители в чатах не участвуют» — отменено, 24.10.2026.)
3. Ученики и родители чужих детей никогда не могут писать друг другу — жёсткий запрет, не настраивается.
4. Журнал действий неизменяем, даже для владельца.
5. CRM: единый инбокс Instagram + WhatsApp, каждый новый собеседник автоматически становится лидом.
6. Строгая безопасность: 2FA для сотрудников, управление сессиями, журнал, маскирование персональных данных.
7. Дизайн: цвета логотипа (navy #01225F, red #BB1027), утверждённый прототип в docs/design/.

## Решения по второму кругу тестирования (04.11.2026)

8. **Блокировка за неоплату (QA C-3).** Одна общая проверка (`app/services/access.py`). Заблокированный ученик не может: отправлять сообщения в чаты, загружать файлы, делать ДЗ и тесты, заказывать в магазине коинов. Оставлено сознательно: чтение чатов, расписание, баланс и оплаты, книги и коины (просмотр), правила и согласия, жалобы. Родители не блокируются никогда: они платят и пишут школе по поводу оплаты.
9. **Неудачные входы (QA B-4).** Аккаунт не блокируется. Ошибки считаются по паре «телефон + IP»: после 5 ошибок с этого IP пауза 30 с, дальше вдвое больше, до 15 мин. Верный пароль с устройства, где уже входили (cookie `oe_device` / заголовок `X-Device-Token` в приложении), или с IP, откуда у пользователя была сессия, пускает всегда. 10 отказов по одному телефону за час — уведомление владельцам.
10. **Заморозка (QA B-5, Правила стр. 362).** Только для ученика со статусом «учится», с сегодняшнего дня или позже, и только при предоплате за месяц: на балансе должно быть не меньше `freeze_prepaid_lessons` уроков (по умолчанию 12 = 3 урока в неделю × 4). Дата окончания — первый день после заморозки. Ночная задача сама ставит «заморожен» в первый день и возвращает «учится» после окончания; «Разморозить» работает, пока статус «заморожен».
11. **Возврат оплаты (QA B-3).** Вернуть можно не больше уроков, чем осталось от этой оплаты (уроки списываются со старых оплат первыми), и не больше денег, чем стоят эти уроки по этой оплате. Возврат 0 уроков и 0 ₸ не принимается. Бонусы и KPI за продажу отменяются полностью при полном возврате и пропорционально — при частичном.
12. **Тест уровня по QR (QA C-2).** Ищем лид по телефону только в филиале QR-кода. Если у лида уже есть уровень, новый результат записывается в историю, а уровень меняет сотрудник.
13. **Время без часового пояса.** Если клиент прислал дату-время без пояса, оно считается временем школы (Asia/Almaty), а не ошибкой. Фильтры по датам («с … по …») включают оба дня по местному времени.
14. **Роль базы для миграций (QA H-7) — пока не делаем.** Сейчас приложение и миграции работают под одной ролью `oneenglish`, владельцем базы, поэтому теоретически приложение может снять триггеры неизменяемости журнала. Отдельная роль-владелец для миграций и роль приложения только с DML-правами потребует переделать установку и права на все таблицы и последовательности; это сделаем перед подключением второй школы или внешних интеграций с доступом к базе. До этого: доступ к серверу и `/etc/one-english/env` только у владельца, триггеры проверяются тестами (`test_security.py`).
